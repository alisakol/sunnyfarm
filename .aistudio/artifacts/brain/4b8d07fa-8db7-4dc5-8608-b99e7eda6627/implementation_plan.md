# План реализации: Активность «Поиск сокровищ» (Treasure Hunt)

## 1. Обзор задачи и согласованные требования
На основе запроса и ответов пользователя создаётся новая увлекательная игровая механика:
- **Тип механики**: Интерактивная мини-игра со старинной картой фермы и долинных земель, оснащённая поисковым компасом-детектором (звуковой/визуальный радар «тепло / холодно» со стрелкой и пульсацией).
- **Структура поиска**: Ежедневная цепочка из **5 спрятанных сундуков** с нарастающим бонусом (1-й деревянный ларец, 2-й кованый сундук, 3-й медный тайник, 4-й серебряный сейф, 5-й древний золотой реликварий). Сундуки спрятаны в разных локациях: на собственной усадьбе (поля, фруктовый сад, мельница) и на территориях соседей (пасека соседа, речная пристань, конюшня).
- **Награды**: Эксклюзивные **коллекционные артефакты** (древний золотой серп, солнечный компас дедушки, изумрудный жёлудь плодородия, янтарный клевер удачи, рунный колокольчик и др.) + **гемы 💎** и ценные ресурсы, а также прогресс в музейную витрину артефактов в «Дневнике фермера».

## 2. Архитектура и визуальный дизайн интерфейса

### А. Атмосфера и оформление (Анти-slop, винтажная картография)
- **Стилистика**: Пергаментная фактурная карта долины с художественными ориентирами (река, родовой амбар, пастбище, ветряк, мост к соседям).
- **Компас-детектор (Compass Radar)**:
  - Интерактивный латунный компас с плавающей стрелкой, указывающей приблизительное направление к спрятанному сундуку.
  - Индикатор дистанции: «Ледяной след» ❄️ ➔ «Прохладно» 🍃 ➔ «Теплеет» 🌤️ ➔ «Горячо!» 🔥 ➔ «СУНДУК ЗДЕСЬ!» ✨.
  - Звуковые щелчки детектора (Web Audio синтез) с учащением при приближении.
- **Интерактивные сундуки**:
  - Анимированные 3D-стилизованные сундуки с эффектом открывания (распахивающаяся крышка, фонтан лучей, конфетти, звон золота и блеск гемов).
  - Шкала прогресса ежедневной охоты: `1/5` ➔ `2/5` ➔ `3/5` ➔ `4/5` ➔ `5/5` с нарастающим множителем наград (x1.0, x1.5, x2.0, x2.5, x3.5 + Супер-Артефакт).

### Б. Витрина Артефактов Долины (Artifacts Collection Showcase)
- Коллекция из 8–10 уникальных древних артефактов с художественным описанием, лором и пассивными бонусами для фермы:
  1. *Древний Золотой Серп* (+10% к шансу двойного урожая)
  2. *Солнечный Компас Дедушки* (+5% к скорости созревания)
  3. *Изумрудный Жёлудь Плодородия* (+15 XP за сбор плодов)
  4. *Янтарный Клевер Удачи* (+10% к монетам за доставку заказов)
  5. *Рунный Колокольчик Пастбища* (+5% к скорости продукции коров и овец)
  6. *Амулет Речного Духа* (бонус к улову в рыбалке)
  7. *Бронзовый Ключ Древних* (скидка в магазине декора)
  8. *Звёздная Призма Долины* (+1 гем к ежедневной награде)

## 3. Модели данных и логика состояния (`useGameState`)

### Новые типы в `src/types/game.ts`:
```typescript
export interface TreasureChest {
  id: string;
  step: number; // 1 to 5
  tier: 'wooden' | 'iron' | 'bronze' | 'silver' | 'gold';
  name: string;
  locationName: string; // e.g. "Старый сад у пруда", "Поле подсолнухов соседа"
  sector: 'my_farm' | 'neighbor_farm';
  x: number; // 0 to 100% on map canvas
  y: number; // 0 to 100% on map canvas
  discovered: boolean;
  opened: boolean;
  rewards: {
    gems: number;
    coins: number;
    artifact?: FarmArtifact;
    bonusItem?: { id: string; name: string; emoji: string; count: number };
  };
}

export interface FarmArtifact {
  id: string;
  name: string;
  emoji: string;
  rarity: 'rare' | 'epic' | 'legendary';
  description: string;
  perk: string;
  discoveredAt?: string;
}

export interface TreasureHuntDailyState {
  lastHuntDate: string; // YYYY-MM-DD
  currentStep: number; // 0 to 5
  totalChestsFound: number;
  unlockedArtifactIds: string[];
  activeChests: TreasureChest[];
  mapCluesRevealed: boolean;
}
```

### Логика в `src/hooks/useGameState.ts`:
- Автоматическая проверка дня (`lastHuntDate !== todayStr`): генерация свежей цепочки из 5 точек поиска.
- Метод `openTreasureModal()` / `startTreasureHunt()`.
- Метод `discoverChest(chestId)`: проверка расстояния до клика / компаса, обнаружение тайника.
- Метод `claimChestReward(chestId)`: начисление гемов, монет, добавление артефакта в инвентарь/коллекцию, сохранение в `localStorage` и Firestore Cloud Save.

## 4. Новые компоненты и точки входа

1. **`src/components/TreasureHuntModal.tsx`**:
   - Полноэкранный/модальный интерфейс экспедиции:
   - Стилизованная пергаментная карта с интерактивными точками интереса и туманом поисков.
   - Плавающий функциональный компас со стрелкой, индикатором дистанции и кнопкой сканирования местности.
   - Анимированный сундук с эффектом открывания награды.
   - Вкладка/кнопка «Коллекция Артефактов» с прогрессом собранных реликвий долины.
   - Таймер до следующего ежедневного приключения.

2. **Точки доступа в интерфейсе (`HeaderBar.tsx`, `BottomNav.tsx`, `FarmMapModal.tsx`)**:
   - Кнопка в `HeaderBar.tsx` (золотой значок карты и компаса 🧭 с индикатором готовой охоты `!` / сундуков `0/5`).
   - Интерактивный указатель или сундучок на ферме / у соседей.
   - Интеграция с «Дневником Фермера» (`FarmerJournalModal.tsx`) для просмотра витрины открытых артефактов.

3. **Аудио и тактильные эффекты (`src/utils/audio.ts` & `haptics.ts`)**:
   - Звук щелчков компаса-радара (учащающиеся импульсы).
   - Фанфары нахождения легендарного сундука и звуки пересыпания драгоценных камней.
